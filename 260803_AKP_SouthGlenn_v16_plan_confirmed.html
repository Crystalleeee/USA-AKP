02 · 주방 위치 확정 도면 확인

v15의 시나리오 A/B/C 중 도면이 답을 정했습니다. 급배수·기존 화장실·Janitor·install 베이가 모두 동측 밴드에 있으므로, 주방은 이 밴드에 co-locate합니다.

확정주방 = 동측 서비스 밴드의 기존 ISC(설치 베이) 자리. 근거: ① 급배수·기존 위생배관이 바로 옆(Mens/Womens)에 있어 신규 배관 최소, ② ISC 베이는 기존 바닥 배수를 가진 서비스 공간이라 습식 전용화에 유리, ③ 북측 Receiving과 가까워 식자재 반입 동선이 짧음. 회의의 "F&B 중앙 희망"은 주방을 옮기지 않고 Social·Oasis 좌석을 중앙에 두고 상부 정글짐 통로로 잇는 것으로 충족(v15 유지).
  • 그리스트랩 — 판매시설엔 미설치. 주방을 ISC 자리에 두면 동측 밴드 배수 본관에 근접해 신설 경로가 짧음. 바닥 매립형은 슬래브 파취 → 임대인 승인(임대 조건과 연동).
  • 중앙 F&B — 좌석·라운지는 Social·Oasis(중앙), 조리(습식)만 동측. 물리 결합은 "F&B 위 정글짐 통로"(하중·안전 확인 = 업무 #10).
  • 업무 #1 종결 조건 — 위치는 확정. 남은 것은 관경·인입 지점·그리스트랩 용량으로, 이는 추가 5개 파일의 배관(P) 상세 시트에서 확인.

03 · 화장실 확정 + 용도변경 기구 증설 핵심 리스크

화장실은 기존 Mens 103 / Womens 102 자리(동측, 그리드 5-D)를 재사용·확장합니다. 배관 코어가 거기 있기 때문입니다. 그러나 CS-2가 결정적 문제를 드러냅니다 — 기존 기구 수량이 판매시설 기준이라 키즈파크엔 크게 부족합니다.

개략 수치 — 정확 수량은 A-3 용도 확정 + 2021 IPC 표 + 설계 occupant load 후 산정. 요지: 기존 2기 규모로는 불가.

확정된 리스크 — 화장실 증설 불가피기존 동측 화장실은 판매시설 853명 기준이라, 집회 용도의 키즈파크엔 변기·세면 수량이 크게 부족합니다. 동측 밴드 안에서 화장실 면적을 확장(인접 ISC/Sales Dev 자리 흡수)하고, 유아용 기구·수유실·기저귀 교환대를 신설해야 합니다. 이는 v13이 지목한 "용도 변경 해당 여부"가 해당됨으로 사실상 확정됨을 의미 — 인허가 일정(11–14개월)에 용도변경 심의가 포함됩니다.
  • 동선 — 화장실 입구를 중앙 Social·Oasis에서 보이게 배치해 부모 시야선 유지(리서치 최다 호평 요소). 동측이지만 중앙 베이스캠프에서 직접 접근 동선 확보.
  • 토들러 인접 — 0–2 크롤러존 옆에 별도 기저귀·수유 포인트(메인 화장실과 분리).

04 · 입·퇴장 · 피난 동선

  • 입장 [확정] — 기존 Vestibule 101(남측) 단일 사용. storefront 47'-0" / 도어 M.O. 32'-0". 진입 축 = 남측 vestibule → Public 대기홀 → 샌드비치 코어(중앙). 이 축에서 파사드 영상면이 정면이 되게(v15 2D).
  • 대기홀 [확정] — vestibule 안쪽 Public에 6×8m. 키오스크→QR→데스크→팔찌. 재입장(종일권)은 손목 스탬프 레인 별도.
  • 피난 [확인 필요] — 단일 주출입은 피난 부족. A-1에 남측 외부문 다수·북측 Receiving 문 있음. 비상구 승계·수량·이격거리는 Binder의 Life Safety/Egress 시트(B1)와 추가 파일로 확정. CS-2에 "EXITS 4 provided"(Mercantile 기준) 표기 → 집회 전환 시 피난 폭·수 재계산.
  • NO ENTRY — v13의 정면 양단 진입 불가 구역과 정합. 출입구 증설 없음.
