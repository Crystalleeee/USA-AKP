```

  ① 담당 인원 × 0.20 in  (스프링클러 + EVAC 동시 충족 시 0.15)   … 2021 IBC §1005.3.2
```

## 4. CAD 도면 유의사항 — 우선순위별

### 🔴 C-1. 기존 출구 5개소가 도면에 반영되어 있지 않다

기존 도서상 출구 위치와 신규 존 배치를 대조한 결과:

| 기존 출구 | 위치 | 폭 | 신규 도면상 해당 위치 | 리스크 |
|---|---|---:|---|---|
| EXIT #1 | **북서쪽 모서리** | 34 in | **ADVENTURE ZONE 내부** | 🔴 놀이구조물에 매몰 |
| EXIT #2 | 남측 중앙 | 75 in | LOBBY 부근 | 🟡 대기열 간섭 우려 |
| EXIT #3 | 남측 중앙 | 75 in | LOBBY 부근 | 🟡 동일 |
| EXIT #4 | 북동쪽 (하역) | — | SAND BEACH / 상부 | 🟠 하역동선 상실 여부 확인 |
| EXIT #5 | 남동쪽 | 34 in | NURSING / RESTROOM 부근 | 🟠 실 배치와 충돌 |
| Accessory Exit #1 | 동측 중앙 | 34 in | KITCHEN 부근 | 🟠 주방 내부 통과 불가 |

**EXIT #1을 상실하면 북서쪽 전체가 남측 출구에만 의존**하게 되고, §1005.5(50% 규칙)와 피난거리 250 ft 모두 위태로워진다.
ADVENTURE ZONE 서측 벽면은 도면상 **37,982 mm(125 ft) 연속 벽**으로 개구부가 없다.

**조치**: 놀이구조물 배치 전에 5개 출구 위치를 도면에 먼저 고정하고, 각 출구까지의 피난통로(2,200 mm)를 확보한 뒤 존을 채운다.

### 🔴 C-2. IBC §424 — 놀이구조물 600 sf 상한

2021 IBC **Section 424 (Play Structures)** 는 높이 10 ft 초과 **또는** 면적 150 sf 초과 실내 놀이구조물에 적용된다.

- **개별 놀이구조물 면적 ≤ 600 sf** — 초과 시 건축주무관이 인정하는 **special investigation**(화재안전 특별조사) 필요
- 600 sf 초과 또는 10 ft 초과 → **Chapter 16 구조설계** 적용
- 발포플라스틱(소프트 플레이 파이프폼 포함): UL 1975 또는 NFPA 289(20 kW 착화원) 기준 **최대 열방출률 100 kW 이하**
- 건물과 동일 수준의 소화설비(스프링클러) 적용

도면의 **ADVENTURE ZONE은 단일 구역 6,791 sf** 로, 상한의 11배다.

**조치**
1. ADVENTURE ZONE을 **개별 구조물 단위로 분절**하고 각 구조물 면적을 600 sf 이하로 명기
2. 분절이 불가능하면 화재방재 엔지니어(FPE)의 **special investigation 보고서**를 사전 준비 — 리드타임 긴 항목
3. 놀이구조물 사이 이격거리: Covered Mall 규정(§402.6.2)의 **20 ft(6,096 mm)** 적용 여부를 AHJ에 확인. 적용되면 현재 실측 1.7~2.9 m 간격은 전면 재조정 대상
4. 소프트 플레이 폼 자재의 UL 1975 / NFPA 289 시험성적서를 발주 조건에 포함

### 🔴 C-3. 화장실 규모가 절반 수준

→ §6 참조. 도면 493 sf, 필요 **약 750~1,250 sf**.

### 🟠 W-1. MAZE RUNNER — Special Amusement Area 해당 가능성

7 CCR 1101-12은 **Special Amusement Building**을 "피난경로가 시각·청각적 방해로 즉시 인지되지 않거나, 의도적으로 혼란스럽게 구성된 건물 또는 그 일부"로 정의한다.
2021 IBC **§411 Special Amusement Areas** 도 같은 개념이며, 2021판부터 **탈출방(escape room)** 이 명시적으로 포함됐다.

MAZE RUNNER가 미로형·암전형이면 §411이 적용되어:
- 스프링클러 + **자동 화재감지**
- 화재 감지 시 **혼란 유발 음향·영상 즉시 정지, 조명 자동 증광, 피난 표시 작동**
- **저위치(low-level) 피난유도 표시** 및 바닥면 근접 유도선
- **EVAC (비상방송설비)** — §907.2.12 / §907.5.2.2
- 내장재 Class A 또는 B

**조치**: MAZE RUNNER의 연출 수준(암전·음향·경로 혼란도)을 먼저 확정한다. §411 적용 시 EVAC가 의무화되므로 **0.15 계수를 자동으로 확보**하게 되는 부수효과가 있다. 오히려 유리할 수 있으니 계획 초기에 판단할 것.

### 🟠 W-2. 화장실 위치가 남동쪽 한 곳뿐

- ADVENTURE ZONE 북서단 → RESTROOM 보행거리 약 **72 m (236 ft)**
- IPC §403.3.3 한도(500 ft) 는 통과하나, **유아 시설로는 운영상 부적합**
- 유모차·보호자 동반 이동 기준 편도 3~4분

**조치**: 북서측(ADVENTURE ZONE 인근)에 **제2 화장실 클러스터** 신설 검토. 기존 급배수 간선 위치 확인 필요.

### 🟠 W-3. Common path of travel 75 ft

2021 IBC Table 1006.2.1 기준 Group A의 common path of travel은 **스프링클러 유무와 무관하게 75 ft(22.9 m)** 다.
놀이구조물 내부 깊숙한 지점에서 두 방향 피난이 가능한 지점까지의 거리가 75 ft를 넘으면 안 된다.
ADVENTURE ZONE(18.5 m × 34.1 m)은 단일 진입구조일 경우 초과 가능성이 높다.

**조치**: 놀이구조물에 **최소 2개소 이상의 이격된 탈출구**를 두고, 구조물 내부 최원점 → 개방바닥까지 22.9 m 이내로 설계.

### 🟡 N-1. 서버룸 3개소 분산 배치

SERVER ROOM이 3곳(중앙 상부, 좌하부, 우측)에 흩어져 있다. 통합 또는 BOH 인접 재배치가 유지관리·배선에 유리하다.

### 🟡 N-2. F&B / KITCHEN 인접성

F&B(2,998 sf)와 KITCHEN(821 sf) 사이에 PARTY ROOM 3·4가 끼어 있다.
배선(配膳) 동선이 이용객 동선과 교차한다. **주방→F&B 직결 서비스 동선** 확보 필요.

### 5-3. 등록 수수료 (2027년 1월 1일 이후)

- 운영자 등록비 **$800/년** + 기구당 **$260/년**
- 등록 대상 기구가 8개면 연 $2,880

### 5-4. 트램펄린 운영 요건 (§2-5-4) — 공간설계에 직접 영향

Institutional Trampoline 운영 시 다음이 **강제**된다:

1. 해당 구역을 **물리적으로 폐쇄·차단할 수 있어야 함** (무단 접근 차단)
2. 적격자 부재 시 **폐쇄 가능한 구조**
3. 사용 중 적격자의 **직접 감독** — 육안 감시 및 즉시 소통 가능
4. 모든 이용자에 대한 **교육 및 단계별 숙련도 확인**
5. 트램펄린 주변 벽은 **평활**해야 하며, 높은 곳에서 뛰어내릴 수 있는 선반·구조 금지
6. **1대당 1인**
7. **트램펄린 간 이동 점프 금지**

**공간설계 반영사항**
- TRAMPOLINE / STAR JUMPING 존에 **개폐 가능한 게이트 + 감시 위치(스태프 포스트)** 를 도면에 명시
- 트램펄린 인접 벽면 마감을 **평활 사양**으로 지정, 선반·돌출·계단형 요소 배제
- 존 입구에 교육·브리핑을 위한 **대기 공간** 확보 (동선폭과 별도)
- 1대 1인 원칙 → 목표 회전율 기준으로 **트램펄린 수량 산정** 필요

## 6. 화장실 — 규모·수량 산정

### 6-1. 적용 법령

- **콜로라도주는 배관에 대해 주(州) 통합코드를 운영**한다. 콜로라도 배관심사위원회(Examining Board of Plumbers)가 **2021 IPC**를 채택(2023-05-15 시행, 3 CCR 720-1). 시(市) 코드보다 우선한다.
- 수량 산정: **2021 IBC Table 2902.1 / IPC Table 403.1**
- 접근성: **ADA 2010 Standards** §213, §604, §604.9(아동용) + ICC A117.1-2017

### 6-2. A-3 기준 산정 계수

Arte Park는 A-3 중 **"arcades and gymnasiums"** 행에 해당할 가능성이 높다.

| 기구 | A-3 (arcades·gymnasiums) | 기존 M (Mercantile) | 배율 |
|---|---|---|---|
| 대변기 (남) | **1 : 125** | 1 : 500 | 4배 |
| 대변기 (여) | **1 : 65** | 1 : 500 | **7.7배** |
| 세면기 | **1 : 200** | 1 : 750 | 3.75배 |
| 음수대 | 1 : 500 | 1 : 1,000 | 2배 |
| 청소싱크 | 1 | 1 | — |

### 6-3. 소요 기구 수

남녀 50:50 가정.

| 기구 | 기존 제공 | 케이스 B (867명 / 434:433) | 케이스 A (1,886명 / 943:943) |
|---|---:|---:|---:|
| 대변기 남 | 2 WC + 1 UR | **4** (소변기 최대 2 대체 가능) | **8** |
| 대변기 여 | 3 | **7** | **15** |
| 세면기 남 | 2 | **3** | **5** |
| 세면기 여 | 2 | **3** | **5** |
| 음수대 | 1 | **2** | **4** |
| 청소싱크 | 1 | 1 | 1 |
| **가족·보조사용 화장실** | 없음 | **1개소 필수** | **1개소 필수** |

> **소변기 대체 한도**: 조립(Assembly)·교육(Educational) 용도에서 소변기는 요구 대변기 수의 **67%까지** 대체 가능 (IPC §419.2).
> **가족·보조사용 화장실**: 조립·판매 용도에서 남녀 대변기 합계가 **6개 이상**이면 **1개소 이상 의무** (IPC §403.5). 케이스 B에서 이미 11개 → 의무.

### 6-4. 필요 면적

| 실 | 구성 | 소요 면적 |
|---|---|---:|
| 여자화장실 (케이스 B) | 대변기 7 (휠체어용 60″ 1 + 보행보조용 36″×60″ 1 포함) + 세면기 3 | **약 350 sf** |
| 남자화장실 (케이스 B) | 대변기 2 + 소변기 2 + 세면기 3 | **약 230 sf** |
| 가족·보조사용 화장실 | 60″ 회전반경 + 대변기 + 세면기 + 기저귀교환대 | **약 120 sf** |
| **소계 (케이스 B)** | | **약 700 sf** + 벽체·전실 → **750~850 sf** |
| **소계 (케이스 A)** | 여 640 + 남 420 + 가족 120 | **약 1,180 sf** → **1,250~1,400 sf** |

**도면 실측 RESTROOM = 493 sf.**
→ 케이스 B 기준 **약 1.6배**, 케이스 A 기준 **약 2.6배** 확대가 필요하다.

### 6-5. 아동 시설 특화 설계

| 항목 | 기준 | 설계 반영 |
|---|---|---|
| 아동용 대변기 (ADA §604.9) | 변기 중심선 **벽에서 305–455 mm**, 좌면 높이 **280–430 mm**, 3–12세 기준 | 성인용과 **병설**. 아동용 설치가 요구 수량을 대체하지 않는다 |
| 아동용 세면기 | 높이·무릎공간 아동 치수 | 성인용과 병설 |
| 휠체어 사용 칸 | 1,525 mm(60″) 폭 이상 | 실별 최소 1개소 |
| 보행보조 칸 (§604.8.2) | 대변기+소변기 합계 **6개 이상**이면 추가 의무, 914 mm(36″) × 1,525 mm(60″) | 여자화장실에 해당 |
| 기저귀교환대 | 남·여·가족실 **전부** | 성별 무관 설치 |
| 유모차 진입 | 전실 및 통로 **1,830 mm** | 게이트형 문 회피 |
| 보호자 동반 | 이성 아동 동반 대응 | **단독사용(all-gender) 화장실 뱅크** 6~8개소 구성 권장 |

> **설계 전략 권고**: 대형 갱(gang) 화장실 2개 대신, **단독사용 개별 화장실 6~8개소 + 소규모 갱 화장실** 조합을 권한다.
> 2021 IPC §403.1.2에 따라 **단독사용 화장실의 기구도 요구 수량에 산입**된다. 이성 보호자 동반, 대기열 분산, 프라이버시 측면에서 유아시설에 유리하다.
> 다만 IPC §403.2(남녀 분리 원칙)의 예외 적용 여부는 **관할청 사전 확인 필수**.
