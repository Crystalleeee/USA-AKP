# USA-AKP — Weekly Kids Facilities Digest Archive

This repo archives the weekly US kids facilities news digest (Denver-area
updates, national facility highlights, construction/expansion news, and
marketing trends), produced by a scheduled routine.

## Output language

Write the digest HTML in **Korean (한국어)** — headings, summaries, tags,
and all body text should be in Korean. Keep source links and facility/brand
proper nouns (e.g. "Sky Zone", "Universal Kids Resort") in their original
form; translate everything else. (Requested 2026-08-21.)

## Archive conventions

- One HTML file per week at `archive/YYYY-MM-DD-digest.html`, dated to the
  Monday (or first weekday) of that week's run.
- Update `archive/index.html` to link each new issue, newest first.
- Self-contained HTML: inline CSS, light/dark aware via
  `prefers-color-scheme`, no external asset dependencies.
- If a week has no significant updates, still archive a brief dated summary
  noting that.
